# 首页引文核查

德文：So ist auch die Philosophie ihre Zeit in Gedanken erfaßt.

中文：哲学，是它的时代在思想中的把握。

出处：黑格尔《法哲学原理》序言，1821。选取原句分号后的分句，独立展示时首字母大写，并以句号收束；中文为本站译文。

[德文全文](https://hegel-system.de/de/werke/07/07-01.htm)

[1840年第二版原著扫描，序言第18页](https://hegel.net/hegelwerke/Hegel_Werke_Bd08-Grundlinien_der_Philosophie_des_Rechts_2aufl_1840.pdf)

本句表达哲学对其时代的思想把握，不表示每个现存制度都自动合理。
